# RUNE

Financial Services for the Compute Age.

Static site served by GitHub Pages from the `main` branch at https://runecapital.co (custom domain set in `CNAME`).

- `index.html`: landing page. The dithered landscape is rendered in WebGL (`assets/rune-scene.js`); the cursor opens a lens of ASCII glyphs and drags the image like liquid.
- `manifesto/index.html`: the RUNE manifesto, set over the same live scene (`assets/manifesto.js`, `assets/manifesto.css`).
- `assets/`: hero image, exhibits, dithered historical photographs and scripts.

No build step: edit the HTML and push.
